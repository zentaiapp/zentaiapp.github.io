ScaleVision

How it works

1) Load a photo with your reference object (known size) and the unknown object together. 2) Calibrate: click the two ends of the reference object and enter its real length. 3) Pick a measurement tool and click points on the unknown object. 4) Read the result — every value is an estimate with a confidence level, not an exact measurement.
This tool does manual point-based measurement only — it does not auto-detect edges or correct perspective. Keep the reference and target object flat, on the same plane, and roughly the same distance from the camera for accurate results.
